# Task Tracker Web Application

A full-stack task management system built with React and Node.js + SQLite.

## Features

- Create, read, update, and list tasks
- Mark tasks as completed or pending
- Priority and due-date support
- Form validation
- REST API with SQLite storage

## Tech Stack

**Frontend:** React (fetch API, no Axios)  
**Backend:** Node.js, Express  
**Database:** SQLite

## Installation & Running

### 1️ Clone Repo

```bash
git clone https://github.com/Manju025/task-tracker.git
cd task-tracker

```

### 2 Backend Setup

```bash
cd backend
npm install
node server.js

```

Server runs at: http://localhost:5000

### 3 Frontend Setup

In new terminal,

```bash
cd frontend
npm install
npm start

```

App runs at http://localhost:3000/tasks
